# Frontend Conventions

## OrcaClient is the only API surface

All API access goes through the WASM-backed `OrcaClient` (and the matching UniFFI bindings for native clients). The legacy OpenAPI→TypeScript codegen (`orca gen` / `npm run gen`) has been removed — `OrcaClient` is the typed surface, generated by `declare_tools!{}` in `projects/tools-def/src/lib.rs`.

Raw `fetch()` is never acceptable in app code. If a tool isn't on `OrcaClient`, add it to `declare_tools!{}` — the WASM method is generated for free.

## Types

Types come from the `OrcaClient` `.d.ts` emitted by `wasm-pack`. Never define local interfaces that duplicate them.

## Thin client

The frontend is a thin client — all business logic on the server. No raw `fetch()`, no frontend parsing or normalization. Everything flows through `OrcaClient`.
